## Основные классы

### VacancyAPI (абстрактный)
Определяет интерфейс для работы с API сервисов вакансий.

### HeadHunterAPI
Реализует работу с API hh.ru, включая:
- Подключение к API
- Получение вакансий по ключевому слову
- Обработка ошибок и лимитов

### Vacancy
Класс для представления вакансии с поддержкой:
- Валидации данных
- Сравнения по зарплате
- Сериализации в JSON

### JSONSaver
Реализует сохранение вакансий в JSON-файл с возможностями:
- Добавления без дубликатов
- Фильтрации по критериям
- Удаления вакансий

## Технические особенности

- **Инкапсуляция**: приватные атрибуты классов
- **Наследование**: абстрактные базовые классы
- **Полиморфизм**: единый интерфейс для разных API
- **Валидация**: проверка данных при создании объектов
- **Тестируемость**: внедрение зависимостей для мокирования
